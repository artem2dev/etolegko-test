# Download Speed

Консольный скрипт, который измеряет скорость скачивания по заданному адресу.

Скрипт делает **10 последовательных запросов** к адресу, каждый раз дожидается полного
ответа, считает среднее время запроса и общий объём скачанных данных и печатает скорость
скачивания.

## Требования

- Python 3.9 или новее.
- Сторонние библиотеки не нужны — только стандартная библиотека.

## Запуск

```bash
git clone https://github.com/artem2dev/etolegko-test.git
cd etolegko-test
python3 download_speed.py https://example.com/heavy-image.jpg
```

Единственный аргумент — адрес ресурса (`http://` или `https://`), например тяжёлой
картинки. В Windows вместо `python3` используйте `python` или `py`.

## Пример вывода

```text
Среднее время запроса:  0.194 с
Объём скачанных данных: 60.43 МБ
Скорость скачивания:    31.13 МБ/с
```

## Единицы измерения

| Показатель             | Единица                        | Как считается                            |
| ---------------------- | ------------------------------ | ---------------------------------------- |
| Среднее время запроса  | с — секунды                    | суммарное время 10 запросов ÷ 10         |
| Объём скачанных данных | МБ — мегабайты                 | сумма размеров тел всех 10 ответов       |
| Скорость скачивания    | **МБ/с — мегабайты в секунду** | объём скачанных данных ÷ суммарное время |

1 МБ = 1 000 000 байт. Чтобы перевести скорость в мегабиты в секунду (Мбит/с), умножьте
её на 8.

## Как это работает

- Запросы идут строго по одному: следующий начинается только после того, как предыдущий
  ответ скачан целиком.
- Время запроса — это всё время от установки соединения до получения последнего байта
  тела ответа. Измеряется монотонными часами `time.perf_counter`.
- Объём — это байты тела ответа; заголовки не учитываются.
- Если сервер оборвал ответ раньше, чем передал заявленный в `Content-Length` объём,
  запрос считается неудачным.

## Ошибки

При ошибке скачивания (неверный адрес, сервер недоступен, HTTP-статус 4xx/5xx, оборванный
ответ, 30 секунд без данных от сервера) скрипт печатает сообщение `Ошибка: …` в поток
ошибок и завершается с кодом 1, не выводя результатов. Запуск без адреса показывает
подсказку по использованию и завершается с кодом 2. Успешный запуск — код 0.
